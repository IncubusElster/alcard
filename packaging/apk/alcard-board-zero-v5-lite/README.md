# alcard-board-zero-v5-lite

## English

v5 Lite board profile. It owns /boot/alcard.cfg and conflicts with the standard profile. It omits active optional-sensor overlays for the declared Lite population; the shared BSP/module APK is still installed. Do not infer a different pinout or remove common modules merely from the Lite name.

## Русский

Профиль v5 Lite. Владеет /boot/alcard.cfg и конфликтует со стандартным профилем. Не включает активные overlays отсутствующих в заявленной Lite-комплектации дополнительных датчиков; общий BSP/пакет модулей всё равно устанавливается. Название Lite само по себе не означает другую распиновку или удаление общих модулей.
