# alcard-board-zero-v5

## English

Standard v5 board profile. It depends on the common BSP, owns /boot/alcard.cfg and conflicts with the Lite profile. The exact enabled overlays are defined in the package recipe; the camera line remains commented in the current profile. Physical population and board behavior still require inspection and acceptance.
