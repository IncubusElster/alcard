# alcard-boot-zero

## English

Installs the compiled Cardputer Zero Device Tree overlays. It does not own /boot/alcard.cfg; that file belongs to the selected board-profile package. The source DTS retains the pinned M5Stack origin and GPL-2.0-only notices. Building a DTBO does not prove that a physical device probes correctly.

- [Current component guide](https://github.com/IncubusElster/alcard/blob/main/docs/en/hardware.md).
- [Related contract](https://github.com/IncubusElster/alcard/blob/main/docs/en/boot-updates.md).
- [Authoritative recipe](https://github.com/IncubusElster/alcard/blob/main/packaging/apk/alcard-boot-zero/APKBUILD) and [current package matrix](https://github.com/IncubusElster/alcard/blob/main/docs/en/packaging.md).
- [Current readiness and verification scope](https://github.com/IncubusElster/alcard/blob/main/docs/en/status.md).

## Русский

Устанавливает скомпилированные Device Tree overlays Cardputer Zero. Не владеет /boot/alcard.cfg: файл принадлежит выбранному board-profile пакету. Исходные DTS сохраняют зафиксированное происхождение M5Stack и GPL-2.0-only. Сборка DTBO не подтверждает корректный probe физического устройства.

- [Текущая готовность и область проверок](https://github.com/IncubusElster/alcard/blob/main/docs/ru/status.md).
