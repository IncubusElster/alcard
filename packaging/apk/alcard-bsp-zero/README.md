# alcard-bsp-zero

## English

Dependency-only common BSP metapackage. It pins the compatible kernel, external modules, firmware and boot-overlay packages. It contains no board configuration and no installed payload. Select exactly one board profile in addition to it.

- [Current component guide](https://github.com/IncubusElster/alcard/blob/main/docs/en/packaging.md).
- [Related contract](https://github.com/IncubusElster/alcard/blob/main/docs/en/hardware.md).
- [Authoritative recipe](https://github.com/IncubusElster/alcard/blob/main/packaging/apk/alcard-bsp-zero/APKBUILD) and [current package matrix](https://github.com/IncubusElster/alcard/blob/main/docs/en/packaging.md).
- [Current readiness and verification scope](https://github.com/IncubusElster/alcard/blob/main/docs/en/status.md).

## Русский

Общий BSP-метапакет зависимостей. Он фиксирует совместимые ядро, внешние модули, firmware и boot overlays. Не содержит конфигурацию конкретной комплектации и устанавливаемые файлы. Дополнительно выбирается ровно один board profile.

- [Действующее руководство компонента](https://github.com/IncubusElster/alcard/blob/main/docs/ru/packaging.md).
- [Связанный контракт](https://github.com/IncubusElster/alcard/blob/main/docs/ru/hardware.md).
- [Исходный рецепт](https://github.com/IncubusElster/alcard/blob/main/packaging/apk/alcard-bsp-zero/APKBUILD) и [текущая матрица пакетов](https://github.com/IncubusElster/alcard/blob/main/docs/ru/packaging.md).
- [Текущая готовность и область проверок](https://github.com/IncubusElster/alcard/blob/main/docs/ru/status.md).
