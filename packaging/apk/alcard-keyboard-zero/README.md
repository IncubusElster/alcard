# alcard-keyboard-zero

## English

Data-only noarch APK: XKB symbols alcard(us/ru/es/de), console bmap files, audited .map sources and layouts.json. US is mandatory and first. Physical Fn/Sym behavior belongs to the kernel driver and board DTS; Fn+Esc maps to Meta. Additional letters placed on AltGr require RightAlt, which the built-in keyboard lacks. The saved graphical layout groups take effect at the next login; current generated compositor configuration uses Alt+Shift for group switching.

## Русский

Noarch APK только с данными: XKB symbols alcard(us/ru/es/de), консольные bmap, проверяемые исходники .map и layouts.json. US обязателен и стоит первым.
